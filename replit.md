# Bold Intercontinental

A luxury banking/finance frontend application built with React, Vite, TypeScript, and Tailwind CSS.

## Stack
- **Framework:** React 19 + TypeScript
- **Build tool:** Vite 6
- **Styling:** Tailwind CSS 3 + PostCSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Project structure
- `src/` — all source code
  - `components/` — shared UI components (Header, Hero, Features, Footer, Charts, etc.)
  - `App.tsx` — root app / routing
  - `Dashboard.tsx`, `Cards.tsx`, `Payments.tsx`, `Wallet.tsx`, etc. — page-level views
  - `Login.tsx` — login/auth screen
  - `main.tsx` — entry point
- `index.html` — HTML shell
- `vite.config.ts` — Vite config (serves on port 5000, host 0.0.0.0)

## Running the app
```bash
npm install
npm run dev
```
The dev server starts on port 5000.
